# AnyWhere-Mechanic

## Introduction
AnyWhere Mechanic is a full-stack, on-demand vehicle repair platform engineered to provide immediate roadside assistance. The application leverages real-time geolocation services to dynamically match stranded drivers with certified mobile mechanics based on proximity, service type, and emergency severity. By digitizing mechanic dispatch, scheduling, and service delivery, the platform eliminates traditional towing delays and streamlines the end-to-end automotive repair workflow.

## Setup
<p>Before the setup make sure to install npm and MYSQL</p>
<p>Make sure MYSQL Server is up and running.</p>

#### Frontend Installation
<p>cd AnyWhere-Mechanic</p>
<p>npm i</p>

### Environment Setup
create a .env file with the following variables
1. MYSQL_HOST = 'YOUR MYSQL HOST NAME. Ex: 127.0.0.1 (localhost)'
2. MYSQL_PORT = 'YOUR MYSQL PORT. Default: 3306'
3. MYSQL_USER = 'THE USER THAT HAS ACCESS TO THE DATABASE'
4. MYSQL_PASSWORD = PASSWORD FOR LOGIN PURPOSES TO THE DATABASE'
5. MYSQL_DATABASE = 'THE DATABASE WHERE THE DATA IS STORED'

6. FRONTEND_URL = 'AS THE NAME SUGGESTS'
7. FRONTEND_PORT = 'AS THE NAME SUGGESTS'
8. BACKEND_URL = 'AS THE NAME SUGGESTS'
9. BACKEND_PORT = 'AS THE NAME SUGGESTS'
